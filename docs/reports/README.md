# Emma Review reports

This directory may contain anonymized, reusable engineering reports only.
Do not commit video files, dates, timelines, screenshots, raw model responses,
parent feedback, production database values, credentials, or identity details.

Date-specific benchmark evidence belongs beside the video in the Git-ignored
`.emma-review/` task directory. A committed report should describe only the
test protocol, model configuration, aggregate error pattern, and approved
technical conclusion.
