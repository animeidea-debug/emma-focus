# ADR: Emma Review 使用 ready 清单触发本地候选分析

- 日期：2026-08-02
- 状态：已接受

## 决策

Emma Review 的自动流程在 Mac 本地运行，由 Codex 每天 22:30 启动，轮询当天
书房视频对应的 `.ready/Study_YYYYMMDD.ready.json`，确认后调用本地 VLM。
Pushover 只负责通知家长，不作为程序触发器。

默认轮询窗口为 22:30–00:00，每 60 秒检查一次；窗口来自最近正常逐日 ready
记录（约 22:34–22:59）。

## 原因

- ready 清单由 Video Merge 在 ffprobe、原子改名和文件字节数确认后发布，是可靠的
  机器信号。
- Pushover 是人类通知通道，可能延迟、丢失或重复，不适合作为状态机输入。
- 本地 Mac 能访问挂载的视频和 7B 模型，NAS 不需要持有模型或生产写权限。
- 候选必须停在 `pending_review`，家长审核仍是唯一生产入库入口。

## 安全与幂等

- 触发器只接受 `camera=Study`、精确日期、文件名和字节数匹配的 manifest。
- 同一视频存在可验证的 `pending_review` 候选时跳过重复推理。
- 脚本不读取 PIN、不调用生产 API、不提交、不部署。
- 分析成功、ready 超时和分析失败分别发送一次 Pushover 通知。

## 后续调整

连续观察真实完成时间和本地推理耗时；如出现稳定早于 22:30 或晚于午夜的情况，
只调整 Codex 任务窗口与等待时长，不改变 ready 契约。
